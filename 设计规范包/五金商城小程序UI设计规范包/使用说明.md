# 五金商城小程序 UI 设计规范包

本规范包用于约束 `Wujin-Mall-Mini` 微信小程序的视觉、交互和页面结构。目标是把小程序统一到白底浅灰页面、主题黄色头部、黑色文字、工业五金采购气质的设计系统中。

## 文件说明

| 文件 | 是什么 | 给谁用 |
| --- | --- | --- |
| `AGENTS.md` | 小程序 UI 开发主规范 | 设计、前端、Codex/子代理 |
| `design-tokens.json` | 颜色、字号、间距、圆角、阴影等设计令牌 | 前端实现与检查工具 |
| `README-检查工具.md` | 小程序页面自查与检查脚本建议 | 开发与评审 |
| `样板/页面样板清单.md` | 主要页面结构样板与验收点 | 页面实现者 |

## 三步使用

1. 开发前先读 `AGENTS.md`，确认页面属于哪类业务场景。
2. 写页面时优先使用 `design-tokens.json` 的语义命名，不在页面内随意新增颜色、圆角和字号。
3. 提交前按 `README-检查工具.md` 自查白底、黄头、黑字、底部操作、跳转参数、空错态和微信小程序安全区。

## 适用页面

- 首页搜索与三泳道结果
- 商品 / 工艺 / 原材料详情
- 产业链溯源图谱
- 一键寻源
- 供应能力详情
- 线索进度
- 消息 / 采购沟通
- 我的 / 采购工作台

## 视觉方向

白色页面底、浅灰分区、主题黄色头部、黑色主文字、黄色按钮与选中态。整体要像工业采购工具，不做娱乐化商城，不做厚重后台。
