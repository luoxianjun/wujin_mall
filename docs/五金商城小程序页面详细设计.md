# 五金商城小程序页面详细设计

更新时间：2026-06-24

适用范围：`Wujin-Mall-Mini` 微信小程序 C 端。本文以当前五金主流程为准，覆盖五金搜索、三泳道结果、商品/工艺/材料详情、溯源图谱、一键寻源、供应能力、线索进度、我的/采购工作台等核心页面；`pages.json` 中保留的论坛、活动、IM、抽奖等旧模板页面不进入五金采购主流程，只作为存量页面处理建议记录。

设计基线：采用浅色工业采购风格，参考已生成设计稿 `output/openrouter-icu/wujin-mini-light-industrial-design-board.png`。

## 1. 产品定位

小程序定位为五金工业 B2B 采购入口，帮助采购方从一个关键词出发，完成“搜索商品/材料/工艺 -> 理解产业链关系 -> 找到供应商 -> 提交寻源线索 -> 跟踪报价/成交”的闭环。

核心价值：

- 成品优先：用户搜“膨胀螺丝”“轮胎”等词时，默认看到可采购商品，不让用户迷失在材料或工艺树里。
- 三泳道联动：同一个关键词可以在“成品、加工、原材料”三条泳道切换，保留来源上下文。
- 搜索即溯源：搜索结果里直接给出上游材料、加工能力、供应商候选和溯源图谱入口。
- 采购转化：通过一键寻源、供应能力、线索进度把浏览行为转成询价线索。

## 2. 全局视觉规范

### 2.1 色彩

| 用途 | 颜色 | 使用说明 |
| --- | --- | --- |
| 页面背景 | `#F7F8FA` / `#F8FAFC` | 全局浅灰背景，避免纯白页面缺少层次 |
| 卡片背景 | `#FFFFFF` | 所有业务信息卡、表单、列表项 |
| 主文字 | `#111827` / `#101828` | 标题、价格、关键字段 |
| 次文字 | `#475467` / `#667085` | 描述、说明、辅助字段 |
| 边框 | `#E5E7EB` / `#E4E7EC` | 卡片、输入框、分割线 |
| 品牌黄 | `#F6B800` / `#F8C400` | 主按钮、选中态、评分环、重要标签 |
| 工业黑 | `#111827` | 顶部品牌字、图标、底部导航文字 |
| 风险黄底 | `#FFF8E1` | 跨行业风险提示 |
| 成功绿 | `#12B76A` | 已完成、可供货、已报价 |
| 蓝色辅助 | `#155EEF` | 链接、少量系统提示，不作为主品牌色 |

### 2.2 字体与层级

| 层级 | 建议字号 | 字重 | 场景 |
| --- | --- | --- | --- |
| 页面标题 | `36-42rpx` | 700 | 首页品牌、详情主标题 |
| 卡片标题 | `30-32rpx` | 700 | 模块标题、供应商名称 |
| 正文 | `26-28rpx` | 400/500 | 描述、字段值、列表内容 |
| 辅助文字 | `22-24rpx` | 400 | 标签、时间、说明 |
| 数字强调 | `36-48rpx` | 700 | 匹配度、价格、订单数量 |

原则：页面内不使用大面积深色背景；所有正文优先黑色/深灰；黄色用于“可点击、选中、重点结果”，不能铺满整页。

### 2.3 组件风格

- 卡片圆角：`12-18rpx`，保持工业工具感，不使用过度圆润的大圆角。
- 按钮高度：主按钮 `72-80rpx`，次按钮 `56-68rpx`。
- 输入框高度：搜索框 `64-72rpx`，表单输入 `76rpx`。
- 卡片阴影：浅阴影即可，建议 `0 8rpx 24rpx rgba(17,24,39,0.06)`。
- 图标：线性工业风图标，配合螺丝、轴承、工具、工厂、定位、证书等语义。
- 商品图片：使用真实五金件、标准件、材料卷、加工设备图，不用卡通插画。

## 4. 全局交互规则

### 4.1 搜索上下文

搜索上下文贯穿全流程：

| 参数 | 来源 | 用途 |
| --- | --- | --- |
| `keyword` | 搜索框、热门词、历史词 | 当前搜索词，也是详情、寻源、图谱默认标题 |
| `requestedLane` / `lane` | 用户选择的泳道 | 控制成品、加工、原材料显示内容 |
| `entryPath` | 直接搜索、泳道切换、上游溯源 | 用于后端记录搜索行为与推荐解释 |
| `sourceLane` | 当前默认泳道 | 泳道切换时说明来源 |
| `sourceKeyword` | 上一次关键词 | 溯源、寻源链路保留上下文 |
| `industry` | 行业上下文 | 触发跨行业风险提示与排序策略 |

页面跳转必须保留 `keyword/lane/sourceKeyword/id/entityType`，避免用户从搜索结果进入详情、图谱、寻源后丢失判断依据。

### 4.2 空状态

空状态不使用“暂无数据”作为唯一文案，应给出下一步动作：

- 搜索空：提示“换一个规格/材料/工艺术语试试”，展示热门搜索。
- 候选供应商空：提示“暂无可自动匹配商家，可提交平台寻源”，表单仍可用。
- 图谱空：展示三泳道基础骨架节点，说明“真实关系待平台维护后补齐”。
- 线索空：引导回到一键寻源页创建线索。

### 4.3 加载与失败

- 搜索接口加载文案：`搜索中`。
- 详情接口加载文案：`加载详情`。
- 供应商候选加载文案：`加载供应商`。
- 线索提交加载文案：`提交中`。
- 图谱接口加载文案：`加载图谱`。
- 接口失败时保留页面结构，用兜底数据展示，同时用 toast 提示“当前使用本地示例，稍后重试”。

## 5. 页面详细设计

### 5.1 五金搜索首页 / 三泳道搜索结果

路由：`pages/wujin/search`

业务目标：作为首屏入口，用户输入关键词后立即理解系统判定、三泳道结果、上游溯源和下一步可操作路径。

页面结构：

| 区块 | 内容 | 交互 |
| --- | --- | --- |
| 顶部品牌区 | `五金智采`、副标题“工业五金 B2B 采购平台” | 可保留微信胶囊安全区 |
| 搜索框 | 关键词输入、搜索按钮 | 回车或点击搜索调用 `/wujin/search/result` |
| 三泳道快捷区 | 成品、加工、原材料三枚分段按钮 | 点击后以 `entryPath=LANE_SWITCH` 重新搜索 |
| 热门品类 | 膨胀螺丝、螺母垫圈、轴承、刀具量具、不锈钢、设备备件等 | 点击填入关键词并搜索 |
| 最近搜索 | 最近 8 个去重关键词、清空入口 | 使用本地存储 `WUJIN_SEARCH_HISTORY_KEY` |
| 判定说明卡 | 默认泳道、系统判定说明、上下文提示 | 搜索后展示 |
| 风险提示卡 | 跨行业风险说明 | `riskWarningRequired=true` 时展示 |
| 上游溯源卡 | 溯源说明、一键寻源按钮 | 跳转 `pages/wujin/sourcing` |
| 三泳道摘要列表 | 每条展示泳道名、结果数量、摘要、下一步动作 | 支持查看详情、溯源图谱 |

推荐视觉：

- 白底页面，顶部使用轻微工业网格纹理或淡黄色角标，不做深色头图。
- 搜索按钮使用黄色底、黑色字。
- 三泳道选中态使用黄色底，未选中为浅灰底。
- 结果卡左侧放商品/材料缩略图，右侧展示名称、价格/匹配度、库存/交期。
- “系统判定”卡要像业务解释，不像技术日志；文案示例：“默认展示成品，材料与加工关系可继续下钻”。

主要字段：

| 字段 | 显示方式 |
| --- | --- |
| `keyword` | 搜索框值、结果标题 |
| `defaultLane` | 判定说明主文案 |
| `laneSummaries[].laneName` | 泳道卡标题 |
| `laneSummaries[].resultCount` | 结果数量徽标 |
| `laneSummaries[].summary` | 摘要正文 |
| `laneSummaries[].nextAction` | 下一步动作 |
| `riskWarningText` | 风险提示正文 |
| `contextHint` / `traceHint` | 上下文和溯源提示 |

验收点：

- 未输入关键词时点击搜索，toast 提示“请输入五金商品、材料或工艺关键词”。
- 点击热门词会填充关键词并搜索。
- 搜索成功后历史词去重保存，最多保留 8 个。
- 泳道切换会带上 `sourceLane/sourceKeyword`。
- 每个泳道卡都能进入详情和溯源图谱。

### 5.2 五金详情页

路由：`pages/wujin/detail`

业务目标：承接搜索结果，按当前泳道解释“这个词在成品/加工/原材料下到底是什么”，并引导用户联系供应商或查看溯源。

页面结构：

| 区块 | 内容 | 交互 |
| --- | --- | --- |
| 顶部图片区 | 商品/材料/工艺图片，标题，当前泳道标签 | 顶部返回 |
| 关键指标 | 价格、库存、最小起订、交期、匹配度 | 数据为空时展示兜底说明 |
| 规格参数 | 材质、型号、标准、表面处理、强度等级等 | 表格形式展示 |
| 关系入口 | 供应能力、溯源图谱 | 跳转对应页面 |
| 跨行业差异提示 | 同名材料/工艺在不同行业不可默认互换 | 黄色浅底风险条 |
| 对比展示 | 通用五金 vs 高要求行业 | 两列或卡片列表 |
| 底部动作栏 | 联系供应商、查看溯源 | 固定底部，避免滚动后找不到动作 |

按泳道差异：

| 泳道 | 页面重点 |
| --- | --- |
| 成品 `PRODUCT` | 商品主图、价格、库存、规格、认证、关联工艺、上游材料 |
| 加工 `PROCESS` | 工艺能力、加工精度、设备、适配商品、可承接批量 |
| 原材料 `MATERIAL` | 材料牌号、产地、规格、库存、适用成品、供应方式 |

接口：

- `GET /wujin/detail/entity`
- 请求参数：`id/entityType/lane/keyword/sourceKeyword/industry`

验收点：

- 没有真实接口数据时仍展示当前关键词的兜底详情。
- 从不同泳道进入时，标题和详情区块随泳道变化。
- “供应能力”和“溯源图谱”跳转时必须保留当前上下文。

### 5.3 溯源图谱页

路由：`pages/wujin/trace-map`

业务目标：用可视化方式展示“原材料 -> 加工 -> 成品”的关系，帮助采购方理解上游替代、加工路径和供应风险。

页面结构：

| 区块 | 内容 | 交互 |
| --- | --- | --- |
| 标题区 | `关键词 + 产业链溯源`、摘要说明 | 顶部返回 |
| 筛选条 | 全部、原材料、加工、成品 | 点击筛选节点 |
| 图谱画布 | 三泳道节点、连线、当前节点高亮 | 点击节点进入详情 |
| 图例 | 绿色原材料、橙色加工、黄色/黑色成品 | 固定在画布上方或下方 |
| 关系路径 | `原材料 -> 加工`、`加工 -> 成品` 列表 | 点击路径展开说明 |
| 操作区 | 查看检测报告、导出溯源报告、一键寻源 | 视接口能力逐步开放 |

视觉要求：

- 仍使用浅色背景，图谱画布为白色或浅灰网格，不使用整页黑底。
- 节点边框用泳道色区分：原材料绿、加工橙、成品黄/黑。
- 当前搜索词节点用黄色描边和轻微阴影突出。
- 连线使用细线，箭头方向从上游到下游。

接口：

- `GET /wujin/trace/graph`
- 请求参数：`id/entityType/lane/keyword/sourceKeyword/industry`

验收点：

- 无真实图谱数据时显示三泳道基础骨架。
- 节点数量较多时优先展示首屏关键节点，其他节点折叠。
- 从搜索页和详情页进入时标题必须体现来源关键词。

### 5.4 一键寻源页

路由：`pages/wujin/sourcing`

业务目标：将搜索或溯源行为转化为可处理线索，给用户推荐供应商并提交需求。

页面结构：

| 区块 | 内容 | 交互 |
| --- | --- | --- |
| 上下文卡 | 当前关键词、当前泳道、来源关键词 | 可返回搜索结果 |
| 候选供应商列表 | 供应商名称、匹配度、主营产品、服务说明 | 点击选中供应商 |
| 匹配解释 | 供应能力索引、关系申报、实体兜底等来源 | 展开后查看 |
| 供应能力入口 | 每个候选卡片的“供应能力详情” | 跳转供应能力页 |
| 需求表单 | 联系人、联系方式、需求说明、数量、期望交期、认证要求 | 必填校验 |
| 已选供应商 | 展示已选供应商 chip | 可取消选择 |
| 提交区 | 提交寻源线索、查看线索进度 | 提交成功后出现进度入口 |

候选卡片字段：

| 字段 | 显示方式 |
| --- | --- |
| `supplierName` | 主标题 |
| `matchScore` | 黄色环形分数或右上角徽标 |
| `mainProducts` | 主营标签 |
| `serviceNote` | 服务说明 |
| `serviceArea` | 服务区域 |
| `delivery` | 交期 |
| `stock` | 库存或供给快照 |

接口：

- `GET /wujin/sourcing/supplier-candidates`
- `POST /wujin/sourcing/lead/submit`

表单校验：

- `contactPhone` 必填。
- `requirement` 必填，建议最少 8 个字符。
- 未选择供应商时允许提交，由平台分发。
- 选择供应商后提交，需要把 `supplierId/supplierName` 带给后端。

验收点：

- 候选供应商为空也可以提交线索。
- 提交成功后 toast 提示“寻源线索已提交”。
- 提交成功后可进入线索进度页，带上 `leadId/keyword/lane/sourceKeyword`。

### 5.5 供应能力页

路由：`pages/wujin/supplier-capability`

业务目标：帮助采购方判断某供应商是否有真实供给能力，而不是只看到商家名称。

页面结构：

| 区块 | 内容 |
| --- | --- |
| 供应商摘要 | 供应商名称、认证状态、匹配度、收藏状态 |
| 主营能力 | 主营产品、加工能力、材料供应能力标签 |
| 产能指标 | 年产能、员工人数、设备数量、厂房面积 |
| 库存快照 | 商品/材料名称、库存数量、最小起订、发货时效 |
| 可承接泳道 | 成品、加工、原材料及说明 |
| 资质证书 | ISO、IATF、CE、检测报告等 |
| 服务说明 | 服务区域、报价方式、样品支持、售后说明 |
| 底部动作 | 联系业务、在线询价、加入收藏 |

接口：

- `GET /wujin/sourcing/supplier-capability`
- 请求参数：`supplierId/keyword/lane/sourceKeyword/industry`

验收点：

- 从一键寻源候选进入时优先展示候选数据。
- 真实接口返回后覆盖兜底的主营能力、资质、设备、产能和响应时效。
- 底部“在线询价”可回到一键寻源页并自动带入该供应商。

### 5.6 线索进度 / 询价订单页

路由：`pages/wujin/lead-progress`

业务目标：让用户知道寻源线索是否被分发、供应商是否响应、是否产生报价和成交动作。

页面结构：

| 区块 | 内容 |
| --- | --- |
| 线索摘要 | 关键词、泳道、线索编号、当前状态 |
| 进度时间线 | 已提交、平台分发、供应商响应、商家报价、确认成交/流失 |
| 报价列表 | 供应商、单价、数量、总价、交期、有效期 |
| 跟进记录 | 平台备注、商家备注、下次跟进时间 |
| 附件/资质 | 报价单、检测报告、证书 |
| 底部动作 | 批量催单、确认成交、重新寻源 |

状态设计：

| 状态 | 视觉 |
| --- | --- |
| `SUBMITTED` | 第一步绿色完成 |
| `MATCHING` / `PENDING` | 当前步骤黄色激活 |
| `ASSIGNED` / `DISPATCHED` | 平台分发完成 |
| `CONTACTED` | 供应商已联系 |
| `QUOTED` | 报价卡可见 |
| `CONVERTED` | 成交成功，绿色完成 |
| `LOST` | 灰色结束，可重新寻源 |

接口：

- `GET /wujin/sourcing/lead/progress`
- 请求参数：`leadId/keyword/lane/sourceKeyword`

验收点：

- 没有 `leadId` 时显示“请先提交寻源线索”的空状态。
- 每个步骤有标题、时间、描述。
- 已报价状态必须显示报价卡和确认成交入口。

## 6. 存量非主流程页面处理

## 9. 页面验收清单

视觉验收：

- 页面整体为白色/浅灰背景，主文字为黑色/深灰。
- 黄色只用于按钮、选中态、评分、进度和重点提示。
- 卡片、列表、表单间距统一，移动端不拥挤、不溢出。
- 底部导航只显示五金、寻源、溯源、我的。
- 旧校园/论坛/活动文案不得出现在五金主流程。

功能验收：

- 首屏默认进入五金搜索。
- 搜索、历史词、热门词、泳道切换可用。
- 搜索结果可进入详情、图谱和寻源。
- 寻源页可选择候选供应商并提交线索。
- 提交成功后可查看线索进度。
- 详情、供应能力、线索进度、图谱在接口失败时有兜底展示。

工程验收：

- `pages/wujin/search` 不预加载 TUIKit。
- `pages/profile/index` 改造后不再引用旧校园社区统计字段作为主内容。
- 新增/改造页面通过微信小程序构建。
- 关键结构测试覆盖路由、按钮、接口路径、主流程裁剪。
